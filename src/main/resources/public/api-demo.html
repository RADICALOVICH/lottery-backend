Нажми одну из кнопок ниже, чтобы выполнить запрос к API.

1. Базовые проверки

API Health

GET /health

Проверяет, что backend-приложение запущено и отвечает.

Database Health

GET /health/db

Проверяет подключение приложения к PostgreSQL.

Draws

GET /draws

Получает список тиражей. Можно показать все тиражи или отфильтровать по статусу.

2. Авторизация

Вход админа

POST /auth/login

Использует seed-админа из миграции: admin / admin123.

Регистрация пользователя

POST /auth/register

Создаёт обычного пользователя для покупки билетов. Пароль должен быть не короче 8 символов.

Вход пользователя

POST /auth/login

Получает user JWT-токен и сохраняет его на странице.

3. Admin-сценарии

Проверить admin-доступ

GET /admin/ping

Проверяет, что admin token подходит для защищённых ручек.

Создать тираж

POST /admin/draws

Создаёт новый тираж и сохраняет его id для следующих шагов.

Запустить розыгрыш

POST /admin/draws/{id}/run-draw

Запускает розыгрыш по выбранному drawId. Тираж должен быть CLOSED и иметь проданные билеты.

4. User-сценарии

Мой профиль

GET /users/me

Проверяет user token и показывает текущего пользователя.

Купить билет

POST /draws/{id}/tickets

Покупает билет в выбранном тираже от имени пользователя.

Мои билеты

GET /me/tickets

Показывает билеты текущего пользователя.

Мои результаты

GET /me/results

Показывает выигрышные/результирующие билеты пользователя.

5. Результаты и отчёты

Результат тиража

GET /draws/{id}/result

Показывает результат конкретного тиража.

Отчёт по завершённым тиражам

GET /admin/reports/draws/completed

Admin-запрос. Возвращает JSON-отчёт по завершённым тиражам.

Вошедшие пользователи

GET /admin/logged-in-users

Показывает пользователей, у которых сейчас есть токены в памяти приложения.

6. Проверка авторизации и ошибок

Выйти как пользователь

POST /auth/logout

Завершает пользовательскую сессию и сохраняет старый user token для проверки.

Проверить старый user token

GET /users/me

После logout старый user token должен вернуть 401 Unauthorized.

Выйти как админ

POST /auth/logout

Завершает admin-сессию и сохраняет старый admin token для проверки.

Проверить старый admin token

GET /admin/ping

После logout старый admin token должен вернуть 401 Unauthorized.

User token в admin endpoint

GET /admin/ping

Проверяет, что обычный пользователь не может пройти в admin-ручку.

Покупка билета с admin token

POST /draws/{id}/tickets

Проверяет, что админ не может покупать билеты. Ожидаемый результат: 403 Forbidden.

Покупка билета без токена

POST /draws/{id}/tickets

Проверяет, что купить билет без Authorization нельзя.
